# VTweaks

**A streamlined gameplay utility for Multi Theft Auto: San Andreas.**

VTweaks is a Windows application designed for MTA:SA players, bringing essential gameplay macros, camera shake reduction, movement enhancements, and a built-in crosshair together in one application.

Built with simplicity and functionality in mind, VTweaks provides a convenient way to manage multiple gameplay tools without relying on separate applications for every feature.

---

## ✨ Features

### 🎮 Gameplay Macros

- **Litefoot**: A dedicated macro for Litefoot gameplay.
- **FastRun**: A macro designed for faster-running input sequences.
- **Anti Camera Shake**: Helps reduce unwanted camera shake for a steadier gameplay experience.

### 🎯 Built-in Crosshair

VTweaks includes an integrated crosshair designed to provide a consistent aiming reference while playing MTA:SA.

- **FSO Support**: Compatible with Fullscreen Optimizations enabled.
- **FSE Support**: Compatible with Fullscreen Exclusive mode.
- **Integrated Overlay**: No separate crosshair application required.
- **Convenient Access**: Keep your crosshair utility alongside your other VTweaks features.

The crosshair is designed to work in both FSO and FSE, giving players flexibility in how they run their game.

### ⚙️ Lightweight & Convenient

- Multiple gameplay utilities in one application.
- A streamlined interface focused on usability.
- Designed specifically for the MTA:SA experience.

## 💻 Requirements

- Windows operating system.
- Grand Theft Auto: San Andreas.
- Multi Theft Auto: San Andreas (MTA:SA).

Additional requirements may depend on the version of VTweaks you use.

---

## 📥 Installation

1. Open the [Releases](../../releases) page.
2. Download the latest available VTweaks release.
3. Extract the archive if necessary.
4. Launch VTweaks.
5. Enable and configure the features you want to use.
6. Start MTA:SA and test your preferred settings.

Only run executables obtained from sources you trust.

---

## 🚀 Getting Started

1. Launch VTweaks.
2. Configure your preferred gameplay macros.
3. Enable Anti Camera Shake if desired.
4. Set up the built-in crosshair.
5. Run MTA:SA in either FSO or FSE mode and verify that the crosshair displays correctly.

Feature behavior may vary depending on your game configuration and server.
